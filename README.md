# Строймаркет — демонстрационный шаблон

Отдельный проект магазина стройматериалов. Каталог, поиск, избранное и локальная корзина. Без платежей и отправки заказов. Цены и наличие условные.

Изображения сайта-образца перечислены в asset-sources.json. Перед коммерческим использованием замените их собственными или разрешёнными изображениями.
